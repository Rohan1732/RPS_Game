# Rock Paper Scissors Game

A simple Rock Paper Scissors game made using HTML, CSS and JavaScript.

## Live Demo

[Play the Game](https://rps-game-puce.vercel.app/)

## Screenshot

![Rock Paper Scissors Game](game-screenshot.png)

## Features

- Play Rock Paper Scissors against the computer
- Computer randomly selects a choice
- User and computer scores are displayed
- Shows whether you Win, Lose or Draw

## Technologies Used

- HTML
- CSS
- JavaScript
